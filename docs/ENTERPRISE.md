# AI智能收款核销系统企业能力

## 领域覆盖

- **银行流水**：接收银行回单、虚拟账户和支付平台到账记录
- **AI客户识别**：综合户名、附言、账号和历史行为识别付款方
- **应收发票**：同步开放发票、贷项、账龄和争议状态
- **智能核销**：执行一对一、一对多、多对一和组合匹配
- **置信度与解释**：展示金额、参考号、日期和客户证据贡献
- **差异处理**：处理短款、长款、手续费、重复到账和未知款
- **核销审批**：按金额、置信度和差异执行职责分离审批
- **退款与转款**：控制退款、跨客户转款和账户验证
- **资金审计**：保留原始流水、模型版本、人工改写和过账回执

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对AI智能收款核销系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `ERP`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
